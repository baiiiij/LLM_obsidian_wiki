# 昇腾硬件架构调研（来源摘要）

> 2026-10-12 网络调研（14 个来源，以 hiascend 官方文档、华为官方 keynote、华为论文为主）。原始笔记：[[昇腾硬件架构调研-2026-10|raw 文件]]。

## 核心结论

- 昇腾计算核心是 **AI Core**（DSA 架构）：Cube（矩阵，占算力 ~99%）+ Vector（宽 SIMD 向量）+ Scalar（控制流）三单元三流水线，配显式管理的 buffer 层级（L1/L0A/L0B/L0C/UB）与 MTE DMA 引擎——与 GPU 的 cache 体系完全不同的哲学
- 910B 起 AI Core 拆为 **AIC（Cube 核）+ AIV（Vector 核）**，向量核数量翻倍
- 产品谱系：310P（推理，LPDDR4X）→ 910 → 910B（~320 TFLOPS FP16 / 64 GB HBM2e）→ **910C = 双 910B die 封装**（~800 TFLOPS / 128 GB / 3.2 TB/s）→ roadmap 950（2026，FP8 + 自研 HBM + SIMD/SIMT 混合）→ 960/970
- 系统侧：CloudMatrix 384 超节点（384×910C）以 scale-up 设计弥补单芯片差距；互联协议 UnifiedBus 2.0 已开放
- 关键对照：AI Core ↔ SM、Cube ↔ Tensor Core、UB ↔ Shared Memory、MTE ↔ cp.async/TMA、HCCS ↔ NVLink（但 HCCS 是 P2P 无交换芯片）
